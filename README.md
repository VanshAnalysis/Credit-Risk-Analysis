# Credit-Risk-Analysis
A Power BI dashboard designed to analyze borrower behavior, loan performance, and credit risk patterns. It identifies high-risk customer segments, key default drivers, and early warning signals while providing insights to build safer and fairer lending policies.  

📊 Project Overview
This project analyzes a credit risk dataset to identify which borrower groups are more or less likely to default, key factors influencing loan outcomes, and early signs of financial distress.It also provides insights for optimizing loan policies and improving credit portfolio health.

🎯 Objectives
- Identify high-risk and low-risk borrower segments  
- Detect key factors influencing loan defaults  
- Analyze how loan size, term, and interest affect risk  
- Spot early financial warning signals  
- Support data-driven lending strategies  

🧠 Key Insights
- Income, DTI ratio, and employment stability are strong predictors of default  
- Long-term and high-interest loans show higher default probability  
- Past delinquencies and high credit utilization are early risk indicators  
- Data-driven scoring helps design fairer lending policies  

📈 Dashboard Features
- Borrower segmentation by age, income, and employment type  
- Loan performance and default rate visualizations  
- Key risk driver identification using DAX measures  
- Early warning system for potential defaulters  
- Policy simulation for safer lending  

🔍 Dashboard Sections
1. Borrower Risk Segments – Who defaults?  
2. Key Risk Drivers – What causes default?  
3. Loan Terms & Risk – How loan features affect risk  
4. Early Warning Signals – Detect financial trouble sooner  
5. Policy & Strategy Insights – Make lending safer and fairer  

🚀 Outcome
The dashboard empowers financial institutions to make data-driven credit decisions, minimize default risk and improve portfolio performance.
